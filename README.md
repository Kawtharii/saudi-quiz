# منصة المسابقة التفاعلية للتاريخ السعودي 🇸🇦
### مخصصة لطالبات الصف السادس الابتدائي • تكريم الطالبة: البتول الهاجري

---

## 📖 نبذة عن المشروع
منصة إلكترونية تعليمية تفاعلية مصممة وفق أحدث معايير تجربة المستخدم (UI/UX) وبألوان باستيل هادئة ومبهجة تناسب طالبات المرحلة الابتدائية. تهدف المنصة إلى ترسيخ وتكريم المعرفة التاريخية ببطولات ومحطات الدولة السعودية الأولى عبر مسار تنافسي ممتع ومحفز.

---

## ✨ المميزات التفاعلية للمنصة
1. **نمط الألوان (Pastel Palette):** ألوان باستيلية متنوعة، مريحة للعين، مع هوية تراثية تعكس أصالة وعراقة تاريخ المملكة (الدرعية وقصر سلوى وبطولات الأجداد).
2. **الصفحة الترحيبية (Landing Page):** واجهة مشوقة بزر انطلاق فوري وشارات تعليمية.
3. **شبكة اختيار الأسئلة (Board View):** 8 بطاقات مرقمة بألوان باستيل جذابة وتأثيرات رفع بصرية، مع شريط تقدم وإنجاز تفاعلي.
4. **نظام التظليل والتجميد (Disabled State):** فور حل السؤال، يتغير مظهره وتظهر علامة "✓ مكتمل" ويتم تجميده لمنع التكرار.
5. **نظام المحاولتين (2-Attempt Counter):**
   - **المحاولة الأولى الخاطئة:** تنبيه تشجيعي لطيف مع تلميح مساعد وإتاحة الفرصة الثانية لاختيار الإجابة الصحيحة من نفس الشاشة مع تعطيل الخيار الخاطئ.
   - **المحاولة الثانية الخاطئة:** توضيح الإجابة الصحيحة وشرحها التاريخي ونقل الطالبة للوحة.
   - **الإجابة الصحيحة:** مؤثرات صوتية مبهجة، قصاصات احتفالية ملونة (Confetti)، وشرح تاريخي موثق.
6. **مؤثرات صوتية ذاتية (Web Audio API):** مؤثرات نغمية مبهجة دون الحاجة لتحميل ملفات صوتية خارجية أو اتصال إنترنت إضافي.
7. **شاشة التكريم والشهادة الفاخرة (Grand Celebration):**
   - احتفال كامل ببالونات الباستيل الطافية والقصاصات الرقمية.
   - شهادة شكر وتكريم فخمة باسم الطالبة: **البتول الهاجري**.
   - المرحلة الدراسية: **الصف السادس الابتدائي**.
   - إمكانية طباعة أو حفظ الشهادة بصيغة PDF فوراً بزر الطباعة المخصص والمتجاوب.
